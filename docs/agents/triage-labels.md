# Triage labels

The engineering skills use these five canonical triage roles. Record the corresponding value in each spec or ticket's `Triage:` line.

| Role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the work. |
| `needs-info` | `needs-info` | More information is needed before work can proceed. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

Use the local label matching the role named by a skill. `Status:` separately records lifecycle progress (`todo`, `in-progress`, `done`, or `cancelled`).
